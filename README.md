# CSEDU Department Website


## Overview

The **CSEDU Department Website** is a full-stack web application
developed to serve as the official website for the **Computer Science &
Engineering Department of the University of Dhaka**.

It provides a centralized platform for students, faculty, and
administrators to access academic resources, stay updated with
announcements, and manage departmental activities efficiently.

------------------------------------------------------------------------

## Features

-   👤 **User Management**
    -   Authentication and authorization
    -   Role-based access (Admin, Faculty, Student)
-   📚 **Academic Resources**
    -   Course materials
    -   Syllabus and curriculum details
    -   Study resources
-   📢 **Announcements**
    -   Department notices
    -   Important updates
-   📅 **Event Scheduling**
    -   Upcoming events
    -   Event management system
-   🧑‍🏫 **Faculty & Staff Information**
    -   Profiles and contact details

## Installation & Setup

### Prerequisites

-   Node.js
-   Python 3.8+
-   npm / yarn
-   Database (PostgreSQL/MySQL)

------------------------------------------------------------------------

### 1. Clone the Repository

git clone https://github.com/srayhan706/CSEDU-Website.git 
cd CSEDU-Website

------------------------------------------------------------------------

### 2. Backend Setup (FastAPI)

cd backend pip install -r requirements.txt uvicorn main:app --reload

------------------------------------------------------------------------

### 3. Frontend Setup (Next.js)

cd frontend npm install npm run dev
